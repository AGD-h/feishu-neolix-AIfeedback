# 教练沟通会 · 深度方案提问话术

**会议时间**：2026年8月10日 14:00
**核心目标**：拿到教练对深度冲刺方案的方向性反馈，避免接下来6天做无用功

---

## 📌 提问总原则

1. **先展示再提问**：每个问题前先用30秒说清楚我们的想法和做法，再问教练意见
2. **不要问开放式问题**："教练您觉得怎么样"→ 教练不好回答；给两个选项让教练选，教练更容易给出明确反馈
3. **被质疑不要辩解**：教练说"这个方向不对"，先记下来，追问"您觉得应该往哪个方向调？"
4. **拿到具体建议**：不要满足于"挺好的""加油"，要追问到具体可执行的动作

## 问题一：AI周报深度方向验证

### 开场（30秒）

> "教练，我们接下来一周想把AI分析这个方向打深。目前的周报是看本周的问题聚类——TOP问题是什么、根因是什么、建议是什么。我们想加一层**跨周追踪**：上周周报里提的TOP问题，这周有没有解决、改善了还是恶化了。
>
> 打个比方，上周说'柜门打不开是P0问题'，这周我们的周报会自动追踪：这个问题出现频次是降了还是升了、对应的改进行动有没有人跟进、同类问题是不是还在其他城市出现。这样从'一次性报告'变成'持续改进闭环'。
>
> 我们纠结的是——**从评委视角看，这种'闭环追踪能力'和'单次报告的分析深度'，哪个更能打动评委？**"

### 教练可能的回答与应对

| 教练回答 | 你的回应 | 追问 |
|---------|---------|------|
| **"闭环追踪更打动人"** | "好的，那我们重点做这块。" | → 追问："跨周追踪我们想展示'问题→行动→效果'这条链，您觉得除了频次变化，还有什么指标能证明改进有效？比如响应时间缩短？满意度上升？" |
| **"单次分析深度更重要"** | "明白，那我们把精力放在让分析更准更深。" | → 追问："您说的深度，是指根因分析要更细（比如追到具体零部件/具体流程环节），还是指建议要更可落地（直接说'改哪个按钮''调哪个参数'）？" |
| **"两个都要做但要有侧重"** | "理解，时间有限我们需要排优先级。" | → 追问："如果只有3天时间做这一块，您建议我们70%精力放在哪？30%放在哪？" |
| **"你们这个闭环追踪太理想化了，真实业务里谁来标记'问题已解决'？"** | "您说得对，这是个实际问题。我们想的是……"（说你的方案：AI根据问题频次变化自动判断趋势，不需要人工标记） | → 追问："如果不用人工标记，靠AI自动检测频次变化和情绪变化来判断问题是否改善，这个逻辑在评委看来会不会显得太'自动化'、缺乏人工干预的可信度？" |
| **"周报只是输出，你们有没有想过做实时的？"** | "实时的我们在P0告警那块已经做了——P0问题5分钟内推送到负责人。周报是给产品团队做周度复盘用的，和实时告警是两个场景。" | → 追问："您觉得路演时实时告警和周报复盘这两个场景，时间分配怎么安排更好？" |

### 如果教练说"这个方向可以"（模糊肯定）

不要满足，继续追问：
> "教练，为了确保我们做的方向不偏，我再确认一下——您觉得评委看到'跨周问题追踪'时，最可能质疑的点是什么？我们提前在材料里把这个质疑回答掉。"

## 问题二：H5反馈入口价值判断

### 开场（30秒）

> "第二个问题关于用户入口。目前我们用的是飞书多维表格的公开表单链接生成二维码，能跑通但确实比较简陋——就是飞书默认的表单样式，没有品牌感，也没有'AI正在分析'的反馈感。
>
> 有队友建议我们花1.5天左右做一个品牌化的H5反馈页面：新石器品牌色、车辆图片、提交后有动画反馈、能看到AI正在分类的过程、最后显示工单号和预计响应时间。
>
> 我们在评估这个投入的性价比——**1.5天做H5，对最终评分的提升大吗？还是说把这1.5天花在其他地方（比如把AI分析做得更深、或者多跑一些真实数据）效果更好？**"

### 教练可能的回答与应对

| 教练回答 | 你的回应 | 追问 |
|---------|---------|------|
| **"H5值得做，第一印象很重要"** | "好的，那我们做。" | → 追问："H5页面您觉得最关键要展示什么？是品牌感（好看）、还是反馈感（让用户看到AI在工作）、还是功能性（一车一码的二维码管理系统）？哪个权重最高？" |
| **"没必要做H5，飞书表单够用了"** | "明白，那我们把表单稍微美化一下就行，不单独开发。" | → 追问："那不做H5的话，这1.5天您建议我们投到哪里？是多接入真实数据、还是做更炫的可视化大屏、还是打磨路演？" |
| **"简单做个H5就行，不要花太多时间"** | "好的，那我们控制在1天内，做一个轻量版——品牌色+提交页+结果页，不做复杂的二维码后台。" | → 追问："轻量版H5您觉得最不能省的要素是什么？" |
| **"二维码管理系统比H5页面更重要"** | "您说的是一车一码的批量生成和管理能力——给每台车生成唯一二维码、可下载打印、能追踪是哪台车反馈的？" | → 追问："这个二维码管理您觉得是做成一个简单的管理页面（输入车牌号→生成二维码图片）就行，还是需要更完整的车辆管理后台？" |
| **"你们飞书表单已经能实现一车一码了，为什么还要重做？"** | "飞书表单确实能通过URL参数预填vehicle_id实现一车一码，问题是：第一样式太简陋不像产品，第二提交后没有反馈（用户不知道AI在处理），第三工单号和响应时间看不到。" | → 追问："如果我们只解决这三个问题中的一个——品牌样式、提交反馈、工单号展示，您觉得解决哪个效果最好？" |

### 如果教练问"你们技术上能做出来吗？"

> "技术上没问题，我们用React+Tailwind做前端，通过飞书开放平台API提交数据到多维表格，和现有系统完全对接。主要是时间成本——1.5天能不能做好、做到什么程度。"

## 问题三：最大短板诊断（最关键的问题）

### 开场（20秒）

> "最后一个问题可能最直接。教练您看过不少入围项目了，**站在评委视角，您觉得我们这个项目目前最大的短板或者最容易被扣分的地方是什么？** 是技术深度不够、业务场景太窄、视觉呈现太糙、还是其他方面？
>
> 我们想把剩下6天时间花在刀刃上，不想做完了才发现评委一眼看出来硬伤。"

### 教练可能的回答与应对

这个问题是开放式的，教练可能指出任何问题。关键是**不要辩解、深挖到底**。

| 教练指出的短板 | 你的第一反应 | 继续追问 |
|-------------|------------|---------|
| **"视觉呈现太糙了"** | "感谢教练直言，这确实是我们的弱项。" | → "视觉上您指的是哪块最需要提升？是Dashboard图表、飞书文档排版、还是整体UI的一致性？有没有具体参考项目或者风格建议？" |
| **"技术深度不够，都是用现成的东西拼的"** | "理解，我们确实是'零代码为主'，这块可能被质疑'技术含量不高'。" | → "您觉得技术深度怎么体现？是多写一些自研的算法逻辑、还是展示更复杂的AI调用链、还是在某个功能点上做到极致（比如聚类准确率验证）？零代码方案在比赛中是不是不占优势？" |
| **"仿真数据没说服力"** | "这也是我们担心的。我们已经写了SerpAPI采集真实社媒数据的脚本，但还没有跑出完整结果。" | → "如果我们能采集一批真实的公开舆情数据混到演示里，但量不大（可能几十条），够不够？还是必须要有企业给的真实业务数据？用公开数据+仿真数据混合的方式评委会接受吗？" |
| **"场景太单一，只做了反馈收集"** | "您是说我们只覆盖了'反馈进来→分类→报告'这条线，但缺了后续的动作环节？" | → "您觉得加什么场景最能补全？比如反馈驱动的产品迭代跟踪？运维人员的工单处理工作台？用户端的反馈进度查询？哪个最有价值？" |
| **"商业价值说不清楚"** | "我们现在说'提升70%效率'，但都是测算数字，可能没说服力。" | → "商业价值是要算清楚ROI（投入多少人天/省多少钱），还是要找到可对比的行业案例，还是要做一个量化的价值模型？" |
| **"创新点不够突出"** | "我们的创新是'交叉聚合AI架构'——飞书AI做实时+DeepSeek做聚类+AI问数做交互，但可能讲得不够清晰。" | → "您觉得这个交叉聚合的点算创新吗？还是需要找一个更sharp的点？比如'AI闭环''零代码落地'这类标签？" |
| **"没什么大问题，继续做就行"** | 😐 不要满足！ | → "教练，我们知道肯定有提升空间，哪怕是小问题也想听听。您觉得路演演示的时候，最容易翻车或者被评委问住的是哪个环节？我们提前准备。" |

## 🎯 教练回答后的统一收尾话术

不管教练给了什么建议，最后都用这段话收尾：

> "谢谢教练！我们整理一下您今天的建议：[简要重复1-2个核心建议]。接下来6天我们会按这个方向冲刺，8月16号提交。
>
> 如果过程中遇到具体问题，我们在群里@您请教，不打扰您太多时间。"

然后记录：教练说了什么、哪些要做、哪些不要做、有什么具体建议——立刻记在手机备忘录里，不要开完会就忘了。

## ⚠️ 注意事项

1. **不要辩论**：教练说"这个方向不对"，哪怕你觉得对，也先记下来，会下再讨论，现场不要争
2. **不要解释太多**：每个问题开场控制在30秒内，留给教练说话的时间（教练会70%时间在说话才对）
3. **带笔记本**：至少一个人专门记录，不要全靠脑子记
4. **三个问题问完就停**：如果教练还有其他建议，认真听；不要主动加问题占用太多时间
5. **态度**：这不是答辩，是请教。姿态是"我们方向不确定，请教练指导"，不是"我们做了这么多您看看多牛"
