# 新石器无人车 AI 反馈 H5 演示操作手册

## 一、启动本地开发服务

### 1. 前置条件
- 已安装 Node.js 16+（推荐 18+）
- 电脑和手机连接**同一个 WiFi 网络**

### 2. 启动步骤
打开终端，进入项目目录：

```bash
cd d:\AIContest\feishu-neolix-AIfeedback\h5
npm install        # 首次运行需要安装依赖
npm run dev        # 启动开发服务器
```

启动成功后，终端会输出类似以下信息：

```
  VITE v5.4.21  ready in 672 ms

  ➜  Local:   http://localhost:3001/
  ➜  Network: http://192.168.x.x:3001/
```

> **重要**：`Network` 后面的地址（如 `http://192.168.31.83:3001/`）是手机访问的地址。如果端口号变化（如被占用会自动切换到 3002、3003 等），请以终端实际输出为准。

## 二、手机访问方法

### 方式一：手机浏览器直接访问（推荐）

确保手机和电脑连接同一 WiFi，然后：

| 手机类型 | 操作方法 |
|---------|---------|
| **iPhone** | 打开 Safari → 地址栏输入终端显示的 `Network` 地址（如 `http://192.168.31.83:3001/`） |
| **Android** | 打开 Chrome / 自带浏览器 → 地址栏输入同样的 Network 地址 |

> 💡 **提示**：建议将页面添加到手机主屏幕，体验更像原生 App：
> - iPhone：Safari → 底部分享按钮 → "添加到主屏幕"
> - Android：Chrome → 右上角菜单 → "添加到主屏幕"

### 方式二：扫码访问（生成二维码）

在电脑终端中运行以下命令可以生成二维码，手机扫码直接打开：

```bash
npx qrcode-terminal "http://192.168.31.83:3001/?vid=NEOLIX001&model=新石器X3&city=北京&loc=望京SOHO"
```

将输出的 IP 地址替换为你终端显示的实际地址。

## 四、演示步骤

### 场景一：正常提交流程（成功路径）

1. **打开首页**：访问演示链接，确认显示车辆信息（车牌号、车型、城市、位置）
2. **点击「开始反馈」**：进入反馈表单页
3. **填写反馈内容**：
   - 输入文字，例如："车辆在路口突然停下，挡住了行人"
   - （可选）选择问题分类：安全/故障/体验/投诉/建议
   - （可选）填写联系方式
4. **点击「提交反馈」**：
   - 页面进入"AI 分析中..."状态（约 2.5 秒模拟等待）
   - 自动跳转到结果页，显示：
     - ✅ 提交成功提示
     - 工单编号（格式：NEO + 日期 + 4位随机数）
     - AI 识别的分类和优先级
     - 预计响应时间
5. **查看日志**：点击右下角 🐛 图标，可看到完整的提交流程日志

### 场景二：模拟后端失败（错误处理路径）

**方法 A：URL 参数方式**

在链接中添加 `mock=fail` 参数：
```
http://192.168.31.83:3001/?vid=NEOLIX001&mock=fail
```
或指定具体失败类型：
- `mock=network` → 模拟网络断开
- `mock=server` 或 `mock=500` → 模拟服务器 500 错误
- `mock=timeout` → 模拟请求超时（8秒）

**方法 B：调试面板切换（推荐）**

1. 正常打开演示链接
2. 点击右下角 🐛 图标打开调试面板
3. 在面板顶部的「模拟模式」区域点击对应的失败类型：
   - ✅ **成功** — 正常提交
   - 📵 **断网** — 模拟网络连接失败
   - 💥 **500** — 模拟服务器内部错误
   - ⏱️ **超时** — 模拟请求超时
4. 正常填写表单并提交，即可看到错误页面
5. 在错误页测试「重新提交」和「返回首页」按钮
6. 切回「成功」模式后点击「重新提交」，可验证从失败恢复到成功的完整流程

### 场景三：AI 自动分类演示

不需要手动选择分类，直接输入对应关键词即可验证 AI 分类效果：

| 输入关键词示例 | 预期分类 | 优先级 |
|--------------|---------|--------|
| "撞到人了！车辆碰撞行人" | 安全 | P0（5分钟响应） |
| "车不动了，屏幕黑屏，打不开" | 故障 | P1（30分钟响应） |
| "你们服务太差了，要求赔偿" | 投诉 | P1（30分钟响应） |
| "建议增加语音提示功能" | 建议 | P3（24小时响应） |
| "今天天气不错" | 体验 | P2（2小时响应） |

### 场景四：连续失败后的智能降级提示

演示系统在用户连续多次提交失败后的人性化处理逻辑：

1. **准备**：打开演示链接，通过 🐛 调试面板将模拟模式切换到「断网」
2. **第一次失败**：填写内容提交 → 进入错误页，显示"已重试 1 次"，底部有「重新提交」和「返回首页」按钮
3. **第二次失败**：点击「重新提交」→ 再次失败，显示"已重试 2 次"，按钮仍然可见
4. **第三次失败**：再次点击「重新提交」→ 页面出现红色提示框 🎯：
   - 标题：**「建议联系人工客服」**
   - 说明文字："已连续失败 3 次，可能是网络或服务器问题，您可以直接联系管理员处理"
   - 客服电话：400-xxx-xxxx（点击右侧复制按钮可一键复制）
   - 客服微信：Neolix-Support（点击右侧复制按钮可一键复制）
5. **恢复验证**：在调试面板切回「成功」模式 → 点击「重新提交」→ 成功跳转到结果页，失败计数重置为 0

> 设计意图：避免用户在网络异常时反复重试产生挫败感，主动提供人工客服通道兜底。

## 五、调试工具使用说明

页面右下角的 🐛 瓢虫按钮是调试面板，支持：

- **实时日志**：显示所有页面操作、API 调用、AI 分析过程
- **日志级别**：🔵信息 🟢成功 🟡警告 🔴错误（红色角标显示错误数量）
- **模拟模式切换**：一键切换成功/断网/500/超时模式
- **清空日志**：点击 🗑️ 图标
- **展开/收起**：点击 ⬆️/⬇️ 图标调整面板高度

控制台快捷命令（F12 打开开发者工具）：
```js
__logger.getLogs()       // 查看所有日志
__setMockMode('fail')    // 切换到失败模式（同 network_error）
__setMockMode('success') // 切换回成功模式
__setMockMode('timeout') // 切换到超时模式
```

## 六、常见问题

**Q: 手机打不开页面？**
1. 确认手机和电脑连接的是**同一个 WiFi**（不是一个连 2.4G 一个连 5G 也不行，需要同网段）
2. 确认 Windows 防火墙没有拦截 Node.js，首次运行时弹出的防火墙提示请点击"允许访问"
3. 关闭电脑上的 VPN 或代理软件
4. 在电脑浏览器上先访问 `http://localhost:端口号` 确认服务正常
5. 检查终端输出的端口号，如果端口变化（如从 3000 变到 3001），手机也要用新端口

**Q: 页面在手机上显示很小或被放大？**
- 确保地址栏 URL 正确，页面已配置移动端 viewport，在手机浏览器中应该自动适配屏幕宽度
- 如果在微信中打开，可能会有微信内置浏览器的缓存问题，建议用 Safari/Chrome 打开

**Q: 提交后一直在"AI 分析中"转圈？**
- 如果设置了 `mock=timeout`，会等待 8 秒才超时，这是正常现象
- 如果不是超时模式，检查网络连接和开发服务器是否还在运行

**Q: 如何恢复到正常模式？**
- 方法1：在调试面板点击「成功」按钮
- 方法2：在控制台执行 `__setMockMode('success')`
- 方法3：关闭标签页，去掉 URL 中的 `mock=` 参数重新打开
